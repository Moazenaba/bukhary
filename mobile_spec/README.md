# 📱 مواصفات تطبيق الموبايل لمنظومة مسجد الإمام البخاري
## Bukhari Competition Management System - Mobile App Specification Suite

تم إعداد هذا المجلد ليكون المرجع الهندسي والتصميمي الشامل والمتكامل لبناء تطبيق الموبايل (سواء بتقنية Flutter أو React Native أو Swift أو Kotlin Jetpack Compose)، دون أي نقص في المتطلبات الوظيفية أو قواعد البيانات أو الهوية التصميمية.

---

### 📂 فهرس ملفات المواصفات:

1. **[DESIGN.md](./DESIGN.md)**: 
   - نظام التصميم الكامل (Design System): الألوان، الخطوط، التدرجات، المسافات، الظلال، الأيقونات، الحركات، وتجربة المستخدم (UI/UX).
2. **[SYSTEM_OVERVIEW.md](./SYSTEM_OVERVIEW.md)**:
   - نظرة عامة على المنظومة، رحلة المستخدم، دورة حياة اللجان والمراحل الـ 9، ومنطق العمل (Business Logic).
3. **[SCREENS_AND_COMPONENTS.md](./SCREENS_AND_COMPONENTS.md)**:
   - تفصيل دقيق لكل شاشة (Screens)، البطاقات (Cards)، النوافذ المنبثقة (Modals & Bottom Sheets)، والحالات المختلفة (Loading, Empty, Error).
4. **[DATABASE_SCHEMA.md](./DATABASE_SCHEMA.md)**:
   - المخطط الكامل لقاعدة بيانات Supabase PostgreSQL، الجداول الـ 9، الحقول، المفاتيح، والقيود.
5. **[API_SPECIFICATION.md](./API_SPECIFICATION.md)**:
   - توثيق كامل لكافة نقاط الاتصال (REST API Endpoints)، الـ Payloads، وحالات الاستجابة والأخطاء.
6. **[ROLES_AND_PERMISSIONS.md](./ROLES_AND_PERMISSIONS.md)**:
   - مصفوفة الصلاحيات والأدوار الخمسة (RBAC)، والتحكم في ظهور الأزرار وإتاحة الإجراءات.

---

### 🎯 الغرض من المنظومة:
تطبيق لإدارة ومتابعة الدورات والمسابقات العلمية الشرعية بمسجد الإمام البخاري، يشمل:
- متابعة اللجان الميدانية عبر 9 مراحل تشغيلية متتابعة.
- بنك الامتحانات والنماذج الورقية ونماذج الـ PDF.
- جدول وتقويم المهام الميدانية واستلام وتسليم أوراق الإجابات.
- إدارة المستخدمين والمعاونين وتوزيع الصلاحيات ولجان المتابعة.
- ربط سحابي مباشر وفوري مع قاعدة بيانات **Supabase PostgreSQL**.
