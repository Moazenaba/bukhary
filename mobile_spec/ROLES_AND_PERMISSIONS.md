# 👮 الصلاحيات والأدوار (ROLES_AND_PERMISSIONS.md)
## Bukhari Competition Mobile App - Role-Based Access Control (RBAC) Specification

---

## 1. الأدوار الخمسة في المنظومة (The 5 System Roles)

### 👑 1. المشرف العام / مدير النظام (`super_admin`)
- **الوصف**: فضيلة المشرف العام على المسجد ومدير النظام.
- **الصلاحيات**: صلاحيات كاملة 100% (إضافة وتعديل وحذف اللجان، إدارة الدورات، تعيين المعاونين وتعديل صلاحياتهم، إدارة بنك الامتحانات، تصدير التقارير، والتحكم في قاعدة بيانات Supabase).
- **البيانات الافتراضية**: اسم المستخدم: `admin` | كلمة المرور: `504`.

### 👨‍🏫 2. رئيس لجنة واختبارات (`committee_head`)
- **الوصف**: معلم ومشرف على لجان معينة.
- **الصلاحيات**: إدارة اللجان المسندة إليه، اعتماد جاهزية الامتحانات، تدقيق كشوف الدرجات، والاطلاع على بنك الامتحانات.

### 📖 3. معلم / عضو هيئة تدريس (`teacher`)
- **الوصف**: معلم ومقرئ في لجان الاختبار.
- **الصلاحيات**: تصحيح الأسئلة، رصد درجات الطلاب، والتحقق من حفظ المتون.

### 👤 4. معاون ميداني / تنفيذي (`assistant`)
- **الوصف**: معاون ميداني في قاعات الاختبارات.
- **الصلاحيات**: توثيق استلام اللجان، فحص جاهزية القاعات، تنفيذ مهام التقويم الميداني، ومتابعة حضور الطلاب.

### 🔍 5. مراجع ومدقق جودة (`auditor`)
- **الوصف**: مدقق رقابي وإحصائي.
- **الصلاحيات**: صلاحية قراءة واستعراض شاملة لكافة اللجان، الإحصائيات، وسجلات الرقابة بدون صلاحية تعديل.

## 2. الصلاحيات النظامية المعتمدة (System Permission IDs)

| معرف الصلاحية | التسمية | التأثير في شاشات الموبايل |
| :--- | :--- | :--- |
| **`database_sheets`** | قاعدة البيانات والكشوفات | إتاحة تبويب كشف الدورات ومصفوفة المتابعة |
| **`manage_committees`** | إدارة اللجان والمراحل | إتاحة شاشة اللجان وتعديل المراحل التسع |
| **`add_new_committee`** | إضافة لجنة جديدة | ظهور زر `+ إضافة لجنة` في الهيدر والقوائم |
| **`exams_pdf`** | الامتحانات ونماذج الـ PDF | إتاحة بنك الامتحانات ورفع النماذج |
| **`manage_courses`** | إدارة وإضافة الدورات | إتاحة تبويب الدورات وتحديد الدورة النشطة |
| **`calendar_schedule`** | الجدول وتقويم المواعيد | إتاحة تقويم المهام وتحديد إنجاز الأعمال |
| **`progress_stats`** | حساب ونسبة الإنجاز | إتاحة لوحة الإحصائيات والرسوم البيانية |
| **`manage_assistants`** | المعاونون والصلاحيات | إتاحة قبول/رفض المعاونين وتعديل أدوارهم |

## 3. الصلاحيات المخصصة (Custom Permissions)
- يستطيع المشرف العام إضافة أي صلاحية حرة جديدة باسم مخصص (Custom Label)، ويتم حفظها وتخزينها في ملف المستخدم `app_users.permissions`.

---

## 4. شروط حماية الواجهات (UI Guard Logic)

```typescript
// دالة التحقق من الصلاحيات في التطبيق
function canAccess(user: AppUser | null, permissionId: string): boolean {
  if (!user) return false;
  if (user.role === 'super_admin') return true; // المشرف العام يملك كل الصلاحيات
  return user.permissions.includes(permissionId);
}
```
