# 📱 مواصفات الشاشات والمكونات (SCREENS_AND_COMPONENTS.md)
## Bukhari Competition Mobile App - Screen-by-Screen & Component Specification

---

## 1. شاشة تسجيل الدخول وبوابة الدخول المركزية (CentralLoginPortal)

### العناصر التفاعلية:
- **شعار وهيدر المسجد**: أيقونة المسجد (`mosque`) مع العنوان "مسجد الإمام البخاري 1448هـ / 2026م".
- **مؤشر حالة الاتصال بالسيرفر**: نبض حي يوضح حالة الاتصال بسوبابيز وسرعة الاستجابة (Latency ms).
- **تبويبات الدخول**:
  - `تسجيل الدخول بالبيانات`: مدخل البريد/الهاتف + مدخل كلمة المرور + تذكرني + زر "تسجيل الدخول".
  - `طلب انضمام جديد (معاون/معلم)`: مدخل الاسم الكامل + رقم الهاتف + نوع الدور + اختيار كلمة المرور + زر "إرسال طلب الانضمام".
- **شريط التبديل السريع (Demo Quick Switcher)**:
  - يسمح بتبديل الحساب فورياً لتجربة الأدوار (مشرف عام 👑، رئيس لجنة 👨‍🏫، معلم 📖، معاون 👤، مدقق 🔍).

## 2. الشاشة الرئيسية (HomeOverviewView)

### العناصر والبطاقات:
1. **بطاقة الترحيب والهيدر التفاعلي (Hero Card)**:
   - اسم المشرف أو المعاون المسجل ودوره وصلاحياته.
   - عرض الدورة النشطة الحالية (مثال: "دورة الصيف 1447هـ").
2. **شريط العدادات والإحصائيات السريعة (KPI Counters Grid)**:
   - إجمالي اللجان (`totalCommittees`).
   - لجان قيد الامتحان والتصحيح (`activeCommittees`).
   - لجان اكتمل حفلها وتكريمها (`completedCommittees`).
   - إجمالي عدد الطلاب في الدورة (`totalStudents`).
3. **شريط المهام العاجلة لليوم (Today's Tasks Alert Bar)**:
   - مهام الاستلام والتسليم الميداني لليوم مع شارات الأولوية (🔴 عاجل، 🟡 هام، 🟢 عادي).
4. **أزرار الإجراءات السريعة (Quick Action Grid)**:
   - ➕ إضافة لجنة جديدة.
   - 📋 فتح جدول كشف الدورات.
   - 📚 بنك نماذج الامتحانات.
   - 📅 تقويم وجدول المواعيد.
5. **موجز الحفلات القادمة (Upcoming Ceremonies Carousel)**:
   - بطاقات باللجان التي تم تحديد موعد حفلها القريب مع المكان والزمان.

---

## 3. شاشة جدول متابعة الدورة الصيفية (SummerCourseTrackerView)

### الميزات والشكل الميداني:
- **محدد الدورة (Course Dropdown)**: تصفية الكشف بحسب الدورة أو عرض الكل.
- **جدول / بطاقات الصفوف التفاعلية**:
  - رقم اللجنة واسمها.
  - الشيخ والمصلى/القاعة.
  - الكتاب المقرر.
  - **مفاتيح التبديل الميدانية السريعة (Quick Status Switches)**:
    - 📦 مستلم (`delivered`).
    - ✏️ مصحح (`corrected`).
    - 🔍 مراجع (`reviewed`).
    - 📢 معلن (`announced`).
    - 🎓 حفل (`ceremony`).
  - عدد الطلاب في اللجنة.
  - حقل الملاحظات الفورية.
  - زر الإجراءات (فتح تفاصيل اللجنة، تعديل الدورة، حذف).

## 4. شاشة إدارة اللجان والمراحل (CommitteesView)

### العناصر:
- **شريط البحث والتصفية (Search & Filter Bar)**:
  - بحث بالرقم أو اسم اللجنة أو اسم الشيخ أو الكتاب.
  - **أزرار تصفية المراحل الأفقية (Horizontal Stage Tabs)**:
    - الكل (`all`)
    - 📝 التسجيل
    - 🟦 الامتحان
    - 🟠 التصحيح
    - 🔵 التجميع
    - 🟡 المراجعة
    - 🟣 كتابة الكشف
    - 📜 الاعتمادية
    - 📢 إعلان النتيجة
    - 🟢 الحفل
- **بطاقة اللجنة (CommitteeCard)**:
  - رقم اللجنة في شارة مميزة.
  - عنوان اللجنة واسم الجمعية والكتاب المقرر.
  - اسم الشيخ ورقم هاتفه مع زر الاتصال المباشر.
  - شارة المرحلة الحالية النشطة بلونها ورمزها.
  - مسار المراحل المصغر (Mini Progress Dots).
  - أزرار التحكم: (فتح التفاصيل الكاملة، تعديل المرحلة الحالية، حذف).

## 5. النافذة المنبثقة لتفاصيل ومراحل اللجنة (CommitteeDetailModal)

هذه هي أهم نافذة في المنظومة، وتفتح كـ **Full-Screen Modal** أو **Extended Bottom Sheet**:

### الأقسام الداخلية:
1. **مسار المراحل التسع التفاعلي (Interactive 9-Stage Stepper)**:
   - قائمة بالمراحل التسع؛ النقر على أي مرحلة يغير حالتها فورياً مع تسجيل توقيت الإنجاز الدقيق.
2. **توثيق استلام واعتماد المعاون**:
   - `استلام اللجنة`: زر لتوثيق استلام المعاون للجنة وكشوفاتها.
   - `اعتماد جاهزية الامتحان`: زر لتوثيق فحص القاعة وتوزيع الأسئلة.
3. **تفاصيل الشيخ واللجنة**:
   - اسم الشيخ، الهاتف، الدولة، عدد الطلاب، نوع اللجنة (رجال / نساء).
4. **تفاصيل مرحلة التصحيح ورصد الأسئلة (Scoring Stage Details)**:
   - اسم المصحح واسم مراجع التصحيح.
   - قائمة خطوات تصحيح الأسئلة (السؤال 1، 2، 3، إلخ) مع زر اكتمال لكل سؤال ورصد الدرجة.
5. **تفاصيل مرحلة التجميع (Aggregation Stage Details)**:
   - مجمع الدرجات ومراجع التجميع وتأكيد المطابقة.
6. **تفاصيل مرحلة الحفل والتكريم (Ceremony Stage Details)**:
   - تاريخ الحفل، الوقت (مثال: 4 العصر)، المكان، عدد الطلاب المكرمين، وقائمة بأسماء الشيوخ الحاضرين للحفل.

## 6. شاشة بنك الامتحانات (ExamsView)
- عرض نماذج الاختبارات المصنفة بحسب الكتب المقررة.
- بطاقة الامتحان: العنوان، الكتاب، الفرع، الدرجة الكلية، مدة الاختبار، عدد الأسئلة.
- معاينة وتنزيل ملف الـ PDF.
- زر عائم `+` لإضافة نموذج امتحان جديد (`AddExamModal`).

---

## 7. شاشة التقويم وجدول المهام (CalendarScheduleView)
- تقويم أسبوعي / شهري للمواعيد.
- تصنيف المهام بحسب الأولوية:
  - 🔴 **عاجل (Urgent)**
  - 🟡 **هام (High)**
  - 🟢 **عادي (Normal)**
- أنواع المهام: (تسليم أوراق، استلام إجابات، امتحان، تصحيح، مراجعة، حفل، عام).
- خانة اختيار (Checkbox) لتحديد إنجاز المهمة مع حفظ توقيت الإنجاز التلقائي.

---

## 8. شاشة إدارة المعاونين والصلاحيات (AssistantsView)
- **قسم طلبات الانضمام المعلقة (Pending Approvals)**:
  - بطاقة طلب الانضمام مع إمكانية القبول، تحديد الدور، تعيين أرقام اللجان المسندة، وتحديد الصلاحيات.
- **قسم المعاونين والمشرفين المعتمدين**:
  - تعديل الصلاحيات الفردية لكل مستخدم.
  - إضافة صلاحيات مخصصة (Custom Permissions).
